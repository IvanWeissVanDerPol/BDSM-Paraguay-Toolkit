# Guía de Negociación de Venues y Contratos

Conseguir un venue para eventos kink es un arte. Esta guía te ayuda a negociar profesionalmente sin revelar más de lo necesario.

---

## 1. Estrategia de Acercamiento

### El Pitch (Cómo Presentar el Evento)

**NUNCA digas:**
- "Fiesta BDSM"
- "Evento fetichista"
- "Play party"
- "Dungeon"

**SÍ di:**
- "Fiesta temática privada"
- "Evento de arte performático"
- "Reunión de club privado"
- "Fiesta de disfraces para adultos"
- "Evento de teatro inmersivo"

### Script de Primer Contacto
```
"Hola, estamos organizando una fiesta temática privada
para adultos. Es un evento de nicho, artístico, con
dress code elegante y estricto control de invitados.

Buscamos un espacio privado para aproximadamente
[X] personas, el [FECHA], de [HORA] a [HORA].

```

### Preguntas que el Dueño Hará (y Respuestas)

**"¿Qué tipo de evento exactamente?"**
> "Es una fiesta de arte y expresión corporal. Tipo performance, con elementos de teatro. Todo el mundo va disfrazado, es muy visual y estético."

**"¿Va a haber... cosas sexuales?"**
> "Es un evento para adultos con código de vestimenta atrevido, pero no es una orgía. Hay reglas estrictas de conducta y personal de seguridad interno. Cuidamos mucho el espacio."

**"¿Cómo es el público?"**
> "Profesionales de 25-45 años. Gente educada, de buen nivel socioeconómico. Solo entran personas verificadas previamente. No es evento masivo ni abierto al público."

**"¿Qué pasa si hay problemas?"**
> "Tenemos equipo de seguridad propio, protocolos establecidos y un organizador responsable presente toda la noche. Cualquier problema lo manejamos internamente."

## 2. Qué Buscar en un Venue

### Checklist de Evaluación

**Privacidad (Crítico)**
- [ ] ¿Tiene entrada discreta?
- [ ] ¿Los vecinos pueden ver/escuchar?
- [ ] ¿Hay ventanas expuestas a la calle?
- [ ] ¿Estacionamiento privado o alejado?

**Espacio**
- [ ] ¿Capacidad real vs. declarada?
- [ ] ¿Hay zonas separables? (play area, chill zone)
- [ ] ¿Espacio para mobiliario especial?
- [ ] ¿Altura de techo? (importante para suspensión)

**Servicios**
- [ ] ¿Cuántos baños? (1 por cada 15-20 personas mínimo)
- [ ] ¿Climatización? (eventos con poca ropa = calor)
- [ ] ¿Cocina/barra disponible?
- [ ] ¿WiFi? (para check-in digital)

**Sonido**
- [ ] ¿Aislamiento acústico?
- [ ] ¿Restricciones de volumen/horario?
- [ ] ¿Equipo de sonido incluido o traer?

**Seguridad**
- [ ] ¿Salidas de emergencia marcadas?
- [ ] ¿Extintores actualizados?
- [ ] ¿Iluminación de emergencia?
- [ ] ¿Cámaras? (problema de privacidad)

**Logística**
- [ ] ¿Acceso para carga/descarga de equipo?
- [ ] ¿Horario de montaje permitido?
- [ ] ¿Hora límite de desalojo?
- [ ] ¿Limpieza incluida o por cuenta nuestra?

## 3. Red Flags de Venues

### Evitar si:
| Red Flag | Por qué |
|----------|---------|
| Dueño muy curioso sobre "qué exactamente van a hacer" | Puede aparecer a "supervisar" |
| Vecinos muy cercanos sin aislamiento | Quejas garantizadas |
| Solo efectivo, sin contrato | Sin respaldo legal |
| Cámaras en todas partes sin opción de desactivar | Riesgo de privacidad |
| "Yo también me quedo en el evento" | Invasión de espacio |
| Precio demasiado bueno para ser verdad | Probablemente hay trampa |
| No permite ver el espacio antes de pagar | Estafa común |

### Señales Positivas:
- Dueño discreto y profesional
- Ha alquilado para "eventos privados" antes
- Contrato claro con cláusulas específicas
- Flexibilidad en horarios de montaje
- Buenas referencias de otros organizadores

## 4. Negociación de Precio

### Estructura de Costos Típica

| Concepto | Rango Paraguay (Gs) | Notas |
|----------|---------------------|-------|
| Alquiler Quincho (8h) | 800.000 - 2.000.000 | Zona Gran Asunción |
| Salón Privado (6h) | 1.500.000 - 4.000.000 | Centro Asunción |
| Bar/Club Completo | 3.000.000 - 8.000.000 | Con barra y sonido |
| Espacio Industrial | 1.000.000 - 2.500.000 | Galpones, sótanos |
| Garantía (depósito) | 50-100% del alquiler | Reembolsable |

### Tácticas de Negociación

**1. Pedir Descuento por Recurrencia**
> "Si este evento sale bien, planeamos hacer uno mensual. ¿Podemos acordar un precio especial por volumen?"

**2. Ofrecer Días/Horarios Menos Demandados**
> "¿Tienen mejor precio si hacemos el evento un jueves en vez de sábado?"

**3. Reducir Servicios Incluidos**
> "No necesitamos servicio de barra ni personal de ustedes. ¿Eso baja el precio?"

**4. Pago Anticipado**
> "¿Hay descuento si pagamos el total por adelantado en efectivo?"

**5. Prueba Piloto**
> "¿Podemos hacer un primer evento a precio reducido como prueba, y si funciona bien, acordamos precio normal?"

### Lo Que NO Negociar
- Seguridad del espacio
- Salidas de emergencia
- Tiempo suficiente de montaje/desmontaje
- Acceso a baños

## 6. Checklist Día del Evento (Venue)

### Al Llegar (Montaje)
- [ ] Inspeccionar espacio con dueño, documentar estado previo
- [ ] Tomar fotos/video del espacio vacío (evidencia)
- [ ] Verificar funcionamiento de luces, enchufes, baños
- [ ] Confirmar ubicación de extintores y salidas
- [ ] Desactivar/cubrir cámaras según lo acordado
- [ ] Probar equipo de sonido
- [ ] Verificar temperatura/aire acondicionado

### Durante el Evento
- [ ] Mantener vías de emergencia despejadas
- [ ] No exceder capacidad acordada
- [ ] Monitorear niveles de ruido
- [ ] Tener contacto del dueño a mano por emergencias

### Al Terminar (Desmontaje)
- [ ] Recoger TODO el equipo traído
- [ ] Retirar toda la basura
- [ ] Revisar baños y áreas comunes
- [ ] Inspección con dueño (o fotos si no está)
- [ ] Documentar cualquier daño existente
- [ ] Devolver llaves si aplica
- [ ] Obtener confirmación escrita de estado

## 7. Plan B: Contingencias

### Si el Venue Cancela Última Hora

**Prevención:**
- Siempre tener 1-2 venues de backup contactados
- No anunciar venue hasta 48h antes
- Seña no mayor al 50% hasta confirmar

**Si sucede:**
1. Activar venue de backup inmediatamente
2. Comunicar a asistentes: "Cambio de ubicación por razones logísticas"
3. Evaluar reclamo legal si hay contrato firmado

### Si Hay Problemas Durante el Evento

**Vecinos quejándose:**
1. Bajar volumen inmediatamente
2. Organizador habla con vecino (no otros asistentes)
3. Ofrecer disculpas, no confrontar
4. Documentar interacción

**Policía se presenta:**
(Ver protocolo de crisis en documento separado)

**Dueño quiere entrar:**
1. Recordar cláusula de contrato
2. Si insiste: "Permítame consultar con el grupo"
3. Si es emergencia real: Cooperar

## 8. Construir Relaciones a Largo Plazo

### Después de un Evento Exitoso

1. **Agradecer formalmente:**
   > "Gracias por la confianza. El espacio estuvo perfecto.
   > Adjunto las fotos del estado en que quedó."

2. **Pagar puntualmente:** Nada construye más confianza

3. **Ofrecer referencia:**
   > "Si necesitas referencia para otros clientes,
   > con gusto hablo bien de tu espacio."

4. **Reservar siguiente fecha:**
   > "Nos gustaría repetir. ¿Está disponible [FECHA]?"

### Si Hubo Problemas

1. **Asumir responsabilidad** (si corresponde)
2. **Proponer solución** antes de que la pidan
3. **Compensar** si es necesario
4. **Aprender** para no repetir
