LUGAR: ________________________

## Notas de Implementacion

### Google Forms Tips
- Activar "Recopilar emails" para vetting (NO para encuestas anonimas)
- Usar "Validacion de respuestas" para campos obligatorios
- Crear seccion separada para respuestas "Si" a preguntas sensibles

### Almacenamiento de Datos
- Guardar en carpeta de Google Drive con acceso restringido
- Solo Host + Head DM tienen acceso a datos de vetting
- Encuestas anonimas pueden compartirse con el equipo

### GDPR / Proteccion de Datos
- Incluir nota: "Tus datos solo se usan para verificacion"
- Ofrecer opcion de eliminar datos si el miembro se retira
- No compartir datos con terceros
