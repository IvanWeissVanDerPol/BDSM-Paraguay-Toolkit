# Guía de Fiestas Temáticas

Las fiestas temáticas son el puente entre el evento social y la play party. Permiten explorar fantasías a través de la estética sin la presión del juego.

---

## Principios de Diseño de Evento Temático

### Los 5 Pilares
1. **Concepto Claro:** Una idea que se pueda explicar en 1 frase
2. **Estética Consistente:** Decoración, música, iluminación alineadas
3. **Dress Code Accesible:** Que la gente pueda cumplir sin gastar fortuna
4. **Actividades Integradas:** Dinámicas que refuercen el tema
5. **Atmósfera Inmersiva:** Desde que entras, estás "en otro mundo"

## EVENTO 2: Valentine's Dark / Anti-Valentine

### Concepto
"El amor no es solo flores y chocolates"

### Fecha Ideal
Sábado más cercano al 14 de febrero

### Variantes

**Opción A: Romantic Dark**
- Para parejas y exploradores
- Énfasis en intimidad y conexión
- Dress code elegante negro/rojo

**Opción B: Anti-Valentine's**
- Para solteros y cínicos
- Énfasis en diversión y liberación
- Dress code: Negro total, "funeral del amor"

## EVENTO 3: Noche de Máscaras / Masquerade

### Concepto
"Detrás de la máscara, somos libres"

### Fecha Ideal
Cualquier época, ideal para primeros eventos

### Dress Code
- **Obligatorio:** Máscara/antifaz
- **Recomendado:** Elegante formal
- **Nivel:** Vestido de gala, traje, corsés, capa

### Por qué Funciona para Principiantes
- Las máscaras dan sensación de anonimato
- Es "solo una fiesta elegante" para newcomers
- No requiere explicar "fetish" a amigos curiosos
- Estéticamente impresionante para fotos

### Decoración

**Estética:**
- Inspiración: Venecia, siglo XVIII, Eyes Wide Shut
- Colores: Negro, dorado, rojo vino, marfil
- Iluminación: Velas, luz cálida, nunca fría

### Música
- Clásica elegante, ópera, waltz
- Dark classical, neoclassical
- Transición a electronic elegante en la noche

**Artistas:**
- Beethoven, Vivaldi (inicio)
- Dead Can Dance

   - Momento donde todos se quitan la máscara a la vez
   - Dramático, cinematográfico

3. **Juego de Roles Secretos**
   - Al entrar, cada uno recibe un "personaje"
   - Encontrar a tu "pareja" según pistas

## EVENTO 4: Neon / UV Party

### Concepto
"Brilla en la oscuridad"

### Fecha Ideal
Cualquiera, popular en verano

### Dress Code
- Blanco o negro (para que la pintura resalte)
- Accesorios neón/flúor
- Mínimo de ropa incentivado (más piel para pintar)

### Decoración

**Lista de Compras:**
| Item | Cantidad | Costo |
|------|----------|-------|
| Luces UV/Blacklight | 6-8 | Gs. 400.000 |
| Pintura corporal UV | 20 potes | Gs. 300.000 |
| Cintas neón | 10 rollos | Gs. 100.000 |
| Globos neón | 100 | Gs. 50.000 |
| Stickers flúor | 200 | Gs. 30.000 |
| Cuerdas neón (para shibari) | 5 | Gs. 150.000 |
| **TOTAL** | | **Gs. 1.030.000** |

**Setup:**
```
TODA LA LUZ NORMAL APAGADA

ILUMINACIÓN
├── UV en todas las zonas de baile/juego
├── Acentos de LED color
└── CERO luz blanca

ESTACIONES
├── "Paint Station" - Artistas pintando asistentes
├── Espejos para verse
└── Zona de fotos UV
```

### Música
- Synthwave
- Techno colorido
- EDM, Trance

### Actividades

1. **Paint Station**
   - 2-3 artistas pintando gratis a asistentes
   - Diseños predefinidos o libres
   - Consentimiento antes de pintar

2. **Shibari Neón**
   - Demo con cuerdas reactivas a UV
   - Muy visual, impactante

3. **Concurso de Glow**
   - Quién brilla más
   - Categorías: Pintura, outfit, creatividad

### Consideraciones Especiales
- Mucha gente con poca ropa = temperatura sube
- **Aire acondicionado potente obligatorio**
- Pintura UV es difícil de sacar → avisar
- Proveer toallas húmedas para limpieza parcial

### Concepto
"Despedir el año con estilo"

### Fecha
31 de diciembre o último sábado del año

### Dress Code
- Formal de gala
- Negro y dorado predominante
- Máscaras opcionales

### Estructura Especial

```
20:00 - Apertura, cocktails
21:00 - Cena servida (si hay)
22:00 - Zona de juego abre
23:00 - Performance especial
23:45 - Preparación countdown
00:00 - CUENTA REGRESIVA + Brindis
00:30 - Fiesta libre
03:00 - Afterparty/Cierre
```

### Elementos Especiales

1. **Countdown**
   - Pantalla o proyección
   - Champagne para brindis

2. **Ritual de Intenciones**

   - Quemar deseos del año viejo

3. **Photo Booth**
   - Props de año nuevo
