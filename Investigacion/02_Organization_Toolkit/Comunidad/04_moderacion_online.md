# Guía de Moderación de Comunidad Online

El grupo de Telegram/WhatsApp es el "living room" de la comunidad. Cómo se modera define la cultura.

---

## 1. Estructura de Canales Recomendada (Telegram)

### Arquitectura Ideal
```
📢 ANUNCIOS (Solo Admins)
├── Eventos próximos
├── Cambios de política
└── Comunicados oficiales

💬 GENERAL (Moderado)
├── Chat libre de la comunidad
├── Presentaciones de nuevos
└── Conversación casual

📚 EDUCACIÓN (Semi-moderado)
├── Artículos y recursos
├── Debates temáticos
├── Preguntas y respuestas

🔞 CONTENIDO ADULTO (Si aplica, verificar edad)
├── Fotos/videos con consentimiento
├── Discusiones explícitas
└── (Separar para cumplir ToS)

🆘 SOPORTE (Privado con Admins)
├── Reportes de incidentes
├── Quejas confidenciales
└── Solicitudes especiales

📸 POST-EVENTO (Temporal)
├── Fotos aprobadas del evento
├── Agradecimientos
└── Memes y recuerdos
```

### Canales Opcionales
- **Marketplace:** Compra/venta de equipo
- **Eventos Externos:** Info de otras comunidades
- **Memes:** Para no contaminar el general
- **Voz:** Para charlas en vivo

## 2. Roles y Permisos

### Jerarquía de Moderación
| Rol | Responsabilidades | Permisos |
|-----|-------------------|----------|
| **Owner** | Decisiones finales, bans permanentes | Todo |
| **Admin** | Moderación diaria, warnings | Banear, silenciar, borrar, pin |
| **Moderador** | Vigilancia, reportes a admin | Borrar mensajes, reportar |
| **Miembro Verificado** | Participación activa | Enviar mensajes, media |
| **Nuevo** | Período de prueba (7 días) | Solo texto, sin media |

### Proceso de Verificación de Nuevos
1. Solicitud de ingreso (formulario)
2. Revisión por admin (vetting básico)
3. Aprobación → Entra como "Nuevo"
4. 7 días sin incidentes → "Miembro Verificado"
5. Si hay problemas → Expulsión silenciosa

## 3. Reglas de la Comunidad (Template)

```
══════════════════════════════════════════
       REGLAS DE LA COMUNIDAD
══════════════════════════════════════════

📌 LEE ANTES DE PARTICIPAR

1️⃣ RESPETO ABSOLUTO
   • Trata a todos como quieres ser tratado
   • Cero tolerancia a insultos, discriminación
     o lenguaje de odio
   • Respetar pronombres declarados

2️⃣ CONSENTIMIENTO TAMBIÉN ONLINE
   • No enviar contenido explícito sin preguntar
   • No DMs no solicitados con intención sexual
   • "No" significa NO, también en chat

3️⃣ PRIVACIDAD ES SAGRADA
   • Lo que se habla aquí, QUEDA aquí
   • No screenshots sin permiso
   • No compartir identidades reales
   • No mencionar a miembros fuera del grupo

4️⃣ CONTENIDO APROPIADO
   • Fotos personales: Solo en canal designado
   • Nada de menores (cero tolerancia, ban + reporte)
   • No spam ni publicidad no autorizada
   • No política ni religión divisiva

5️⃣ CONFLICTOS
   • Resolver diferencias en privado
   • No "airear ropa sucia" públicamente
   • Si no pueden resolver → Contactar admin
   • Drama público = Warning para ambos

⚠️ VIOLACIONES
   • 1er strike: Advertencia privada
   • 2do strike: Silencio temporal (24-72h)
   • 3er strike: Expulsión
   • Violaciones graves: Expulsión inmediata

📩 CONTACTO: @[admin_handle]

Última actualización: [FECHA]
══════════════════════════════════════════
```

## 4. Sistema de Strikes (Advertencias)

### Niveles de Infracciones

**Nivel 1 - Leve (Warning verbal)**
- Spam accidental
- Off-topic excesivo
- Lenguaje inapropiado menor
- Primera vez olvidando reglas

**Nivel 2 - Moderado (Strike formal)**
- Falta de respeto a otro miembro
- Contenido no solicitado
- Ignorar advertencias previas
- Drama público innecesario

**Nivel 3 - Grave (Expulsión temporal/permanente)**
- Acoso o bullying
- Compartir información privada (doxxing)
- Contenido ilegal
- Violación de consentimiento (aunque sea online)

## 5. Guía de Respuestas para Moderadores

### Situación: Nuevo que rompe reglas sin saber
```
"Hey @[usuario], bienvenido! 👋
Solo un heads-up: [explicar la regla brevemente].
No pasa nada, es tu primer día. Si tienes dudas,
las reglas están en el pin. ¡Disfruta el grupo!"
```

### Situación: Miembro que repite conducta
```
"@[usuario], ya habíamos hablado de esto.
Te mando DM para charlar. Gracias."

[En privado:]
"Hey, necesito que respetes [regla específica].
Esto es tu segundo aviso. Una más y tendré que
silenciarte temporalmente. ¿Todo bien?"
```

### Situación: Conflicto entre dos miembros
```
"@[usuario1] @[usuario2] - Llevemos esto a privado.
Pueden resolverlo entre ustedes o contactar a un admin
si necesitan mediación. Gracias por mantener el general
en paz. 🙏"
```

### Situación: Contenido inapropiado
```
[Borrar mensaje]
[En privado al usuario:]
"Hey, borré tu mensaje porque [razón].
Recordá que ese tipo de contenido va en [canal apropiado]
o directamente no está permitido. No hay drama,
solo mantenemos el espacio ordenado."
```

### Situación: Acoso grave
```
[Silenciar usuario inmediatamente]
[En privado:]
"Tu conducta hacia @[víctima] es inaceptable.
Estás temporalmente silenciado mientras revisamos
el caso. Si tienes algo que agregar, respondé a este
mensaje."

[A la víctima:]
"Hey, vimos lo que pasó. ¿Estás bien?
Tomamos medidas con [usuario]. Si necesitas algo,
estamos acá. Tu bienestar es prioridad."
```

## 6. Manejo de Trolls y Raids

### Señales de Raid/Ataque Coordinado
- Múltiples usuarios nuevos entrando al mismo tiempo
- Mensajes idénticos o muy similares
- Spam de contenido ofensivo
- Links sospechosos

### Protocolo de Emergencia
1. **LOCKDOWN:** Cambiar permisos → Solo admins pueden postear
2. **PURGA:** Banear cuentas atacantes (no responder, solo banear)
3. **LIMPIEZA:** Borrar mensajes spam
4. **COMUNICADO:** Avisar a miembros que fue un ataque externo
5. **REFUERZO:** Temporalmente requerir aprobación para nuevos miembros

### Mensaje Post-Raid
```
"⚠️ AVISO: Tuvimos un raid de trolls externos.
Ya está controlado. Perdón por la molestia.

Si ven cuentas sospechosas, reporten en silencio
(no alimenten a los trolls). Gracias por la paciencia."
```

## 7. Dinámicas de Engagement

### Actividades Semanales Sugeridas

| Día | Actividad | Ejemplo |
|-----|-----------|---------|
| Lunes | Presentaciones | "Lunes de Bienvenida: Nuevos, preséntense!" |
| Martes | Temático | "Martes de Tema: ¿Cuál fue tu primer kink?" |
| Miércoles | Educación | "Miércoles de Mitos: Desmintamos creencias" |
| Jueves | Random | "Jueves de Memes" |
| Viernes | Anticipación | "¿Qué planes para el finde?" |
| Sábado | Libre | - |
| Domingo | Reflexión | "¿Qué aprendiste esta semana?" |

### Actividades Mensuales
- **AMA (Ask Me Anything):** Invitar a un experto/miembro destacado
- **Concurso de Fotos:** Tema del mes (ej: "Tu juguete favorito")
- **Debate Moderado:** Tema polémico con reglas estrictas
- **Aniversarios:** Celebrar miembros que cumplen X tiempo

### Cómo Revivir un Grupo Muerto
1. Admins empiezan conversaciones (no esperar que otros lo hagan)
2. Hacer preguntas directas que requieran respuesta
3. Compartir contenido interesante con opinión propia
4. Mencionar a miembros activos: "@X, ¿vos qué pensás?"
5. Crear sentido de urgencia: "Últimos cupos para evento"

## 8. Manejo de Crisis de Reputación Online

### Escenario: Acusación Pública contra Miembro
```
PROTOCOLO:
1. NO borrar el mensaje inmediatamente (parece censura)
2. Respuesta pública del admin:
   "Vimos esto. Lo estamos investigando seriamente.
   Por respeto a todos, no discutamos públicamente
   hasta tener información completa."
3. Investigar: Hablar con acusador y acusado por separado
4. Tomar decisión basada en evidencia
5. Comunicar resultado (sin detalles privados)
```

### Escenario: Screenshot Filtrado
```
PROTOCOLO:
1. Identificar qué se filtró y dónde apareció
2. Si es contenido sensible → Contactar plataforma para takedown
3. Comunicado interno:
   "Lamentablemente hubo una filtración. Recordamos
   que compartir contenido de este grupo es
   [consecuencia]. Estamos investigando."
4. Si se identifica al responsable → Ban permanente
5. Reforzar reglas de privacidad
```

## 10. Métricas de Salud del Grupo

### KPIs a Monitorear

| Métrica | Saludable | Preocupante |
|---------|-----------|-------------|
| Mensajes/día | 20-100 | <5 o >500 |
| Miembros activos/mes | >30% | <10% |
| Nuevos miembros/mes | 5-15% del total | <1% o >30% |
| Tasa de abandono | <5%/mes | >15%/mes |
| Incidentes de moderación | <3/mes | >10/mes |

### Encuesta de Satisfacción (Trimestral)
```
📊 ENCUESTA RÁPIDA (anónima)

1. ¿Qué tan cómodo te sientes en el grupo? (1-5)
2. ¿Los admins responden a tiempo? (Sí/No/A veces)
3. ¿Hay algo que te gustaría cambiar?
4. ¿Qué tipo de contenido te gustaría ver más?
5. ¿Recomendarías este grupo? (1-10)
```

## 11. Documentación y Transparencia

### Registro de Acciones de Moderación
Mantener un log privado (solo admins) de:
- Fecha y hora
- Usuario afectado
- Acción tomada
- Motivo
- Moderador responsable
- Evidencia (screenshots)

### Transparencia con la Comunidad
- Publicar estadísticas mensuales (sin nombres)
- Ejemplo: "Este mes: 3 warnings, 1 ban temporal, 0 bans permanentes"
- Explicar cambios de reglas antes de implementar
- Permitir feedback sobre moderación

## 12. Burnout del Moderador

### Señales de Alerta
- Responder agresivamente a usuarios
- Evitar entrar al grupo
- Sentir que "nadie aprecia el trabajo"
- Tomar conflictos personalmente

### Prevención
- Rotar responsabilidades entre admins
- Tener al menos 3 moderadores activos
- Establecer "días off" donde otro cubre
- Reunión mensual de admins para desahogar
- Recordar: Es voluntario, está bien tomar breaks

### Si un Mod Necesita Alejarse
```
"@[mod] se toma un descanso de moderación.
Mientras tanto, contacten a @[otro_admin] para temas
urgentes. Gracias @[mod] por todo tu trabajo. 🙌"
```
