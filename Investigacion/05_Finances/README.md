# Finanzas y Presuestos para Eventos

Esta carpeta contiene modelos de estimación financiera para diferentes tipos de eventos BDSM en Paraguay.
Úsalos para calcular riesgos antes de reservar un lugar.

## Índice de Escenarios

1.  **[Munch Comunitario (Low Cost)](01_estimacion_munch_lowcost.md)**

    - _Riesgo Bajo._ Ideal para empezar.
    - Inversión: ~1.2M Gs | Ganancia est: ~500k Gs.

2.  **[Fiesta en Club (Mid Range)](02_estimacion_fiesta_club.md)**

    - _Riesgo Medio._ El estándar de la industria.
    - Inversión: ~3.1M Gs | Ganancia est: ~2.8M Gs.
    - Requiere 42 personas para empatar.

3.  **[Gala High-End (Rooftop)](03_estimacion_gala_highend.md)**

    - _Riesgo Alto._ Evento de imagen/lujo.
    - Inversión: ~10.7M Gs | Ganancia est: ~3.8M Gs.
    - Margen de error muy bajo (necesita 83% de ocupación).

4.  **[Play Party en Quinta (Areguá)](04_estimacion_playparty_quinta.md)**
    - _Logística Compleja._ Evento de inmersión/convivencia.
    - Inversión: ~5M Gs.
    - Incluye pernocte y comida.

---

> [!TIP] > **Regla de Oro:** Siempre ten un fondo de emergencia del 20% sobre tus costos estimados para imprevistos (roturas, coimas, tormentas).
