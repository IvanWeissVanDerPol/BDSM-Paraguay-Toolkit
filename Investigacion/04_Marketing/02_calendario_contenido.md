# Calendario de Contenido y Estrategia Social Anual

## Filosofía de Contenido

**Principio 80/20:**
- 80% Contenido de valor (educación, comunidad, arte)
- 20% Promoción directa (eventos, venta de entradas)

**Los 4 Pilares de Contenido:**
1. **Educación:** Desmitificar, enseñar, normalizar
2. **Comunidad:** Testimonios, behind-the-scenes, celebraciones
3. **Estética:** Arte visual que atraiga sin ser explícito
4. **Convocatoria:** Eventos, talleres, experiencias

## Estrategia de Hashtags (Paraguay)

### Tags Locales (Alto Alcance)
- #AsuncionUnderground #CulturaAlternativaPy #EventosAsuncion
- #ParaguayNocturno #AsuncionNightlife #PyCreativa

### Tags Temáticos (Soft - Instagram Safe)
- #ArteYJuego #Misterio #ClubPrivado #EsteticaOscura
- #ComunidadAlternativa #ExploraciónPersonal #ConsentimientoEsSexy

### Tags a Evitar (Riesgo de Shadowban)
- NO usar en posts públicos: #bdsm, #fetish, #dom, #sub, #kink
- Estos tags solo en Stories efímeras o plataformas adultas (FetLife)

### Estrategia de Rotación
- Usar máximo 15-20 hashtags por post
- Rotar sets de hashtags cada semana para evitar penalizaciones
- Crear 3-4 sets diferentes y alternar

## Plantillas de Copy

### Para Eventos (Instagram)

**Fórmula AIDA:**
```
[HOOK - Pregunta o declaración impactante]
↓
[INTERÉS - Qué es el evento]
↓
[DESEO - Por qué no te lo puedes perder]
↓
[ACCIÓN - Cómo obtener entrada]
```

**Ejemplo:**
```
¿Cuándo fue la última vez que sentiste algo... diferente?

Este [FECHA], abrimos las puertas de [NOMBRE EVENTO].
Una noche donde el arte, el misterio y la conexión
se encuentran en un espacio seguro.

📍 Location: Secret (se revela 24h antes)
🎫 Cupos limitados: Link en bio

No es para todos. Es para quienes entienden.
```

### Para Educación

**Fórmula: Mito → Realidad → Call to Action**
```
❌ MITO: "[Creencia común errónea]"

✅ REALIDAD: [Explicación educativa]

💡 [Dato adicional o recurso]

¿Quieres aprender más? [CTA]
```

### Para Comunidad

**Fórmula: Emoción → Historia → Conexión**
```
[Emoji relevante] [Declaración emocional]

[Breve historia o testimonio]

Esto es lo que significa ser parte de [COMUNIDAD].

#ComunidadAlternativa #[Tags locales]
```

## Métricas a Trackear

### Semanales
- [ ] Alcance de posts
- [ ] Engagement rate (likes + comentarios / seguidores)
- [ ] Nuevos seguidores
- [ ] Mensajes directos recibidos

### Mensuales
- [ ] Crecimiento total de seguidores
- [ ] Posts con mejor rendimiento (Top 3)
- [ ] Conversión: Clicks en link → Formularios completados
- [ ] Nuevos miembros en Telegram

### Por Evento
- [ ] Entradas vendidas vs. Alcance del post promocional
- [ ] Fuente de tráfico (¿cómo se enteraron?)
- [ ] Asistencia real vs. Confirmados
- [ ] NPS post-evento (encuesta)
